# SportsConnect
SportsConnect is an ASP.NET Core MVC web application for managing recreational sports teams and memberships.
The application allows users to register, search for teams, submit membership applications, and track their application status. Team leaders can create teams, review applications, approve or deny requests, and manage team rosters.
The project was built using C#, ASP.NET Core MVC, Entity Framework Core, and SQLite as part of a college software development project.
## Features
- User registration and login
- Create and manage sports teams
- Search teams by sport and location
- Submit membership applications
- Approve or deny membership requests
- View team rosters
- User dashboard showing memberships, applications, and teams managed
- SQLite database with Entity Framework Core
